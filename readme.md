This repo has two parts:

1. A Julia-language notebook using the Monty package for simulating feedstock applications and resulting carbon dioxide drawdown under a constant surface area. This notebook has the ability to generate graphics of deployments via CairoMakie. AND,

2. A Python-language notebook that imports CSVs generated by the first file, computes the cumulative CDR, and ranks them.

Requirements:
Julia 1.10 with a Jupyter Julia kernel (IJulia)
Packages: Monty.jl (from GitHub), Random, Distributions, Meshes, GeoStatsFunctions, GeoStatsProcesses, DataFrames, Statistics, Plots, DimensionalData, CairoMakie, CSV
